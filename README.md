## 第一次提交到 Git

在“FDE 学习终端”里输入（把名字和邮箱换成你自己的）：

```powershell
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
git add .
git commit -m "day01: 完成第一个 Python 脚本"
```

然后到 GitHub 新建一个空仓库 `fde-learning`，按页面提示添加远程地址并推送。
